## სლაიდი 2 — პრობლემა და მიზანი

- ხშირად გამოყენებული კოდის ფრაგმენტების ერთ ადგილას შენახვა.
- სწრაფი ძიება სათაურის, კოდის, აღწერისა და ტეგების მიხედვით.
- მიზანი: ფრაგმენტების დამატება, დალაგება და ხელახლა გამოყენება.

**საჩვენებელი მასალა:** აპის საწყისი ეკრანის სქრინშოტი.

## სლაიდი 3 — მომხმარებლის ძირითადი სცენარი

1. მომხმარებელი ხსნის კატალოგს და ეძებს ფრაგმენტს.

4. აკოპირებს კოდს; ცვლილებები ინახება ბრაუზერში.

**საჩვენებელი მასალა:** README-ის Mermaid დიაგრამა ან მოკლე live demo.

## სლაიდი 4 — ტექნოლოგიები და არქიტექტურა

- React და JavaScript — კომპონენტები, მდგომარეობა და მოქმედებები.
- CSS Grid/Flexbox — განლაგება და რესპონსიულობა.
- Vite — დეველოპმენტი და production build.
- Monaco Editor — კოდის შეყვანა.

**სათქმელი:** `App.jsx` მართავს მონაცემებს და უზიარებს მოქმედებებს გვერდის კომპონენტებს.

## სლაიდი 5 — ინტერფეისი და რესპონსიულობა

- მთავარი გვერდი, ძიება, ენის ფილტრები და ფრაგმენტების ბარათები.
- კატალოგი იყენებს ავტომატურ Grid სვეტებს; მცირე ეკრანებზე გადადის ერთ სვეტზე.
- Hero და ნავიგაცია ერგება ვიწრო viewport-ებს.

**საჩვენებელი მასალა:** ერთი დესკტოპისა და ერთი მობილურის სქრინშოტი. დაამატეთ მხოლოდ რეალურად გადაღებული სურათები.

## სლაიდი 6 — ფუნქციონალის დემო

- მოძებნეთ ფრაგმენტი ტეგით ან სათაურით.
- ჩართეთ ენის/რჩეულების ფილტრი.
- დაამატეთ ახალი ფრაგმენტი და აჩვენეთ ვალიდაცია.
- მონიშნეთ რჩეულად, დააკოპირეთ კოდი, შემდეგ აჩვენეთ რედაქტირება ან წაშლის დადასტურება.

**დემო მონაცემები:** წინასწარ მოამზადეთ მოკლე კოდის ფრაგმენტი და შეამოწმეთ clipboard-ის ნებართვა.
